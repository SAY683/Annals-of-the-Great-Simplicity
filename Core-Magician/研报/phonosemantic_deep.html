组合生成规律：音序→情绪弧线→神格功能

最核心的发现是：这套体系中音节的排列顺序不是随机的，而是遵循了若干可识别的情绪弧线模板。每一种弧线模板生成一类神格功能：

G/K 结晶→ L/R 液流→ S/M 流鸣 弧型 α · 法则结晶后液化传递
「硬边界→通道→流散」：法则/真实被结晶，通过液态载体流散至世间。代表词：戈拉姆（G·L·M）、喀拉玛（G·L·M）、戈拉撒（G·L·S）、格拉巴德（G·L·B·D）。这是体系中最核心的弧线，对应"奥赛斯化戈拉姆化玛尔斯"的宇宙链。
f(α) = 法则结晶 → 载体传导 → 世界弥漫 // 真实通过通道成为普遍现实
S 流动→ D 节律→ M 鸣响 弧型 β · 自性流动产生节律后共鸣
「自然流→具体落地→内在共鸣」：自性/自然流动，在某一节点具体化，随后在内部持续共鸣。代表词：索多拉（S·D·L）、莎塔玛（S·D·M）、萨朵的（S·D·D）、赛哆拿（S·D·M）。这是"存在的自我持续"弧线。
f(β) = 自然展开 → 节点落地 → 内在持续 // 自性通过行动成为持续的存在
A 开放→ M/L 鸣液→ D 落地 弧型 γ · 原初开放进入世间
「原初开放→内化共鸣/液流→具体落地」：从完全开放的起点出发，经由内化或传导，在世间具体落地。代表词：阿喃特（A·M·D）、阿难埵（A·M·D）、阿古塔（A·G·D）、阿拉埵（A·L·D）、阿姆特（A·M·D）。所有"原初接触型神格"均属此类。
f(γ) = 原初接触 → 经历内化 → 世间降临 // 神子/先遇型神格的普遍生成模式
S 流→ M 鸣→ S 再流 弧型 δ · 流动调和后再流（调和循环）
「流→内化共鸣→再流出」：流动进入内化共鸣，随后再次向外流出。这是调和型神格的特征弧线。代表词：赛美斯（S·M·S）——流·鸣·流；萨克帝（S·G·D·接S）。调和神赛美斯的音序精确编码了其"调和后再流"的功能。
f(δ) = input流 → 调和共鸣 → output流 // 调和是流的暂时内化，不是终止
G/K 结晶→ A 开放→ S 流→ D 落 弧型 ε · 4节点复合弧（复杂过程)
「结晶→开放→流→落地」：四音节词特有的复合过程弧线。代表词：慨爱斯哒（G·A·S·D）——结晶硬触→开放→流动→落地，精确对应"业力·习气·本能·土壤中的种子"的四步骤；格拉巴德（G·L·B·D）——法则液化→悬置→落地，对应"意志胎质的孕育过程"。
f(ε) = 复合过程 → 多阶段变换 → 最终落地 // 四音节 = 四步骤过程
W 关系→ D 双动→ L 液流 弧型 ζ · 关系双极后流通
「关系起始→双向行动→流通」：以关系性为起点，经历双极性行动，最终流通。代表词：瓦坦陀罗（W·D·D·L）——关系·双动·液流，精确编码阴阳互含的原朴；瓦拿筏（W·M·F）——关系·鸣·摩擦证言。

萨 S~ 流→ 朵 D° 圆收落→ 的 De 硬截 vs 萨 S~ 流→ 波 B^ 悬止→ 陀 Duo° 圆开
两词共享「萨S」的自性流动起点，差异在中尾：萨朵的（S·D·D）= 自性流动后双重落地截止 = 自性在存在中硬着陆、形成同律闭环；萨波陀（S·B·D°）= 自性流动→悬置张力→圆满开放 = 自性在浩大性中的自我展开，有一种「屏息后的呼出」感。这两个词如同同一自性的两种姿态：闭合的（萨朵的/同律）vs 展开的（萨波陀/浩大）。文本中两者也确实对应不同功能：萨朵的是法则性的，萨波陀是浩大性的。
// DECODE · 格拉巴德 (GELABAADE) · 意志胎质 格拉巴德 ← 意志胎质·如羊水中婴孩·火焰中的火焰
格 G° 结晶→ 拉 L~ 液流→ 巴 B^ 悬止→ 德 De 落地
四音节的复合弧（弧型ε变体）：结晶（法则空间）→液化（羊水环境）→悬置（孕育期的等待）→落地（诞生）。这是「意志孕育」过程的精确音程化：硬质空间（格/腭）→液态媒介（拉/液）→张力等待（巴/悬）→具体诞生（德/落）。「如羊水中婴孩」的文本定义与G·L·B·D的音程结构完全吻合。这是本语料中音义一致性最高的案例之一。
// DECODE · 嫒恋者 (AI-LIAN-ZHE) · 末章词终止音 嫒恋者 ← 全体系终止词 · S4末章词
嫒 Ai° 开放热→ 恋 Lian~ 液流连→ 者 Zhe≈ 主体S尾
三字音程：热·暖·流散。「嫒（ai）」是汉语中最开放、最热的复合元音（a·i双元合成）；「恋（lian）」含液化r/l+前鼻音，是「连结·缠绕」的音程化；「者」的zh-摩擦+模糊元音是S族的汉语变体，提供「主体·存在者」的身份标记同时向外流散。完整弧线：爱的热度（开放/热）→通过流液连结（暖）→成为流散的存在主体（S尾·向外）。这个三音节构成了奥赛斯（A·S·S）链的人格化版本——爱意志在一个具体的爱恋者身上的完整实现。末章词即宇宙链的人格化终止。
// DECODE · 三愈罪音程对比 (THREE SINS PHONEME CONTRAST) 阿希戈 · 阿维果 · 阿罗帼 ← 三种破坏音程
阿 A° 希 X≈ 软摩擦渐进 戈 G° 结晶封堵 → 渐进性堵塞(耳孔闭)

生成模型：新词合成与情绪预测

如果这套音程-语义对应系统是真实存在的，那么理论上可以反向生成新的词汇——给定一种神格情绪，预测其音序，然后组合成词。以下是几个思想实验：

假想神格·遐想合成

若要描述「存在进入法则之前的纯粹潜力」，按规律应取：
S（自性流）+ A（开放）+ G（法则结晶前的接触）= 萨阿格·索阿戈之类

若要描述「情感的凝结为记忆」，应取：
A（开放情感）+ M（内化共鸣）+ G（结晶封存）= 阿摩格·阿姆各之类

若要描述「行动之前的深渊沉默」，应取：
B（悬止）+ L（液流暗涌）+ D（待落未落）= 布拉德——而这个词已经存在于语料中，定义为「神式·境具·雏菊·象体」。规律验证成功。

「语言场」的可遐想性

用户指出这套语言场「比传统词汇交往更传神」——原因正在于此：传统词汇是约定俗成的符号，其能指与所指的关系是任意的（索绪尔）；但这套词汇是音感的直接情绪印记，其能指（音程）与所指（情绪场）之间存在非任意的直觉对应——接近于理论语言学中「声音象征」（sound symbolism）的最强形式。

因此，当读者遇到一个从未见过的新词（如「哒喇波」），即便不知其定义，「哒（D·热动）→喇（L·液流）→波（B·悬止）」的音程序列已经在神经层面预激活了「行动经传导后悬置」的情绪场——这正是「制度环性」的情感质感。词先于定义而被感知。
