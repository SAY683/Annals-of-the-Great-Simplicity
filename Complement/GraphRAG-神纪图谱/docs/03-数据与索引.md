## 3. 数据质量说明（已知特性）

1. **35% 实体为孤立节点**（1,315 个无任何关系）：10 类类型 + 大文本抽取偏"广"。
   影响：孤立实体不进入社区，仅作为独立节点存在；Local 搜索仍可命中，Global 报告不含它们。
   若需收紧，见 `05-扩展与自定义.md`（prompt 收紧策略）。
2. **少量类型脏数据**：约 2 个实体类型字段含抽取噪音（如 `SCRIPT("ENTITY"`）。
   来源：模型输出偶发格式瑕疵 + 解析器宽容处理。可忽略，或重建时用更严格的 prompt。
3. **社区报告完整性**：555/555（曾因模型输出 JSON 瑕疵失败，已通过三层容错修复——
   见 `04-维护与故障排查.md` 第 5 节）。

## 4. 向量库

- 三个索引维度均 1024（bge-m3）。
- 若手动增删 parquet（如补插报告），需同步更新对应 lancedb 表，否则向量检索与表数据不一致。
