# 05 · 扩展与自定义

## 1. 调整实体类型（entity_types）

```yaml
# project\settings.yaml
extract_graph:
  entity_types: [concept, deity, person, place, symbol, event, scripture, organization, object, natural_element]
```

- **10 类是经验甜区**（5~15 为业界经验值）。神学/哲学文本建议保留 concept/deity/symbol/scripture。
- 改成更多类（如数十种）：抽取会更分散、精度下降；建议 ≤15。
- 修改后必须重建索引。

## 2. 修改提示词（prompts\）

`project\prompts\` 下每个 .txt 对应一个环节：
- `extract_graph.txt`：实体/关系抽取（约束输出格式、示例）
- `summarize_descriptions.txt`：描述总结
- `community_report_graph.txt` / `community_report_text.txt`：社区报告
- `local_search_system_prompt.txt` / `global_search_map_system_prompt.txt` / `global_search_reduce_system_prompt.txt` / `drift_search_system_prompt.txt`：四种检索

**收紧抽取（减少 35% 孤立实体）的 prompt 技巧**：
在 extract_graph.txt 的 Steps 里加一句约束，例如：
> "Only include an entity if it has a clear relationship with at least one other entity. Do not extract isolated concepts that have no connections in the text."

## 3. 换模型 / 换 LLM 通道

只改 `settings.yaml` 的 `completion_models`：
- **opencode Go**（当前）：`api_base: http://127.0.0.1:15721/v1`，`model: deepseek-v4-flash`
- **官方 DeepSeek**：`api_base: https://api.deepseek.com` + 真实 key（按 token 计费）
- **Kimi 等其它 OpenAI 兼容**：填对应 api_base + key

换通道后建议清空 `cache\` 再重建（避免旧缓存污染），或接受旧缓存（同模型时安全）。

## 4. 换 / 调向量模型

- bge-m3（1024 维）为当前配置。换模型必须同步改 `vector_store.index_schema` 的 `vector_size`。
- 本地部署：llama-server 加载 GGUF；云 API：改 `api_base` + key（如 OpenAI text-embedding-3-large、硅基流动、智谱）。

## 5. 接入新文本

1. 把新文本放入 `project\input\`（支持 .md/.txt，`file_pattern: .*\.md` 需同步）。
2. 运行 `scripts\03-rebuild-index.bat`。
3. 若想保留多项目：复制整个 `project\` 为 `project2\`，改各自 settings/input，
   用 `GRAPHRAG_PROJECT` 或 `project=` 参数切换。

## 6. 接入其它 AI 宿主（MCP 通用性）

`mcp\graphrag_mcp.py` 是标准 MCP server（stdio），暴露三个工具：
- `graphrag_query(question, method, community_level, project)`
- `graphrag_list_projects(project)`
- `graphrag_get_context(entity, project)`

任何支持 MCP 的宿主（Codex / Claude Code / Cursor / 自研 agent）都能注册调用。
返回统一 JSON：`{ok, method, question, answer, error}`，方便程序化处理。
（接口细节见 `MCP_API_REFERENCE.md`）

## 7. 性能调优

| 参数 | 位置 | 说明 |
|---|---|---|
| concurrent_requests | settings.yaml | 24（opencode 实测 OK）；429 时降 12 |
| max_tokens | call_args | 12000；抽取输出大时可升 16000（更慢） |
| chunk size | chunking.size | 1200；文本密度高可降 800 |
| community_reports.max_input_length | settings.yaml | 8000；大社区报告可降以提速 |
