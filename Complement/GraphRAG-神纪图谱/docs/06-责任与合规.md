# 06 · 责任与合规

## 1. 数据来源与性质

- 源文本：`project\input\神纪_合并版.md`（《神纪》系列，作者自有的神学/哲学虚构典籍文本）。
- 本归档是对该文本的**知识图谱化处理产物**（实体/关系/社区/报告），不引入外部数据。
- 图谱内容反映的是文本自身的世界观设定，属于**虚构文学/哲学作品**范畴。

## 2. 使用边界

- **输出性质**：GraphRAG 回答是对源文本的检索与综合，可能包含文本中的极端设定
  （如神祇的严酷律法、等级观念等）。这些是**文本内角色的主张**，不代表现实立场或建议。
- **不作事实/现实依据**：本图谱仅服务文学分析、写作辅助、作品解读等目的，
  不应作为现实决策、宗教教义、医疗/法律/财务等专业建议的依据。
- **敏感内容**：若源文本含暴力/争议设定，问答输出可能复述之——使用时应保持批判性，
  并结合原文核对引用（回答均带 `[Data: ...]` 引用标记）。

## 3. 数据与隐私

- 向量化在本地（bge-m3 / llama-server），文本不进云端向量服务。
- LLM 生成走 opencode Go（云 API）：**查询内容会发送给第三方**。如对隐私敏感，
  可换本地模型（见 `05-扩展与自定义.md` 第 4 节）或将 `extract_claims` 等保持关闭。
- 归档内不含个人数据；若分发请确认不包含未授权内容。

## 4. 维护责任

- 本归档按"可维修、可理解、可修改"原则组织：配置集中、文档编号、脚本自解释。
- 修改记录建议：在 `README.md` 或归档末尾追加变更日志（本仓库使用 git，请提交）。
- 依赖升级（graphrag 包）后需重打 JSON 容错补丁（见 `04` 第 5 节），建议纳入升级清单。

## 5. 许可

- 本归档供个人/团队在作者授权范围内使用与修改。分发或商用请遵循原仓库 LICENSE 与作者约定。
