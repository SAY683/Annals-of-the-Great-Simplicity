# 02 · 配置详解（settings.yaml）

`project\settings.yaml` 是 GraphRAG 的唯一配置入口。以下逐节说明。

## 1. completion_models（生成模型 = LLM）

```yaml
completion_models:
  default_completion_model:
    model_provider: openai
    model: deepseek-v4-flash
    call_args:                    # ← 透传给每次 LiteLLM 调用的参数
      extra_body:
        reasoning_effort: none    # ← 关键！关闭思考，否则输出为空/极慢
      max_tokens: 12000
    auth_method: api_key
    api_base: http://127.0.0.1:15721/v1   # CC Switch 本地代理（opencode Go）
    api_key: dummy
    retry:
      type: exponential_backoff
```

- `call_args` 是 `ModelConfig` 的透传字段，会合并进每次调用。**`reasoning_effort` 必须放
  `extra_body` 里**——直接放顶层会被 LiteLLM 丢弃（已实测）。
- 换模型/换通道只改这里：`model`、`api_base`、`api_key`。
- 想用官方 DeepSeek：`api_base: https://api.deepseek.com` + 你的 key；但会按 token 计费。

## 2. embedding_models（向量模型）

```yaml
embedding_models:
  default_embedding_model:
    model_provider: openai
    model: bge-m3
    api_base: http://127.0.0.1:8081/v1   # 本地 llama-server
    api_key: local
```

- 换向量模型时**必须同时改 `vector_store.index_schema` 的 `vector_size`**（bge-m3 = 1024）。
- 本机无 GPU 时 bge-m3 FP16 足够；追求更高精度可换 bge-large（但维度不同）。

## 3. chunking（分块）

```yaml
chunking:
  type: tokens
  size: 1200
  overlap: 100
  encoding_model: o200k_base
```

- 1200 token/块对本文本（中文）是经验甜区；块太大→抽取输出易被 max_tokens 截断，块太小→上下文割裂。
- `encoding_model: o200k_base` 用 tiktoken 估算 token。

## 4. entity_types（实体类型——决定抽取方向）

```yaml
extract_graph:
  entity_types:
  - concept      # 概念（爱、觉悟、法界、种子…）
  - deity        # 神祇（玄姬、神姬、吾神…）
  - person       # 人物
  - place        # 地点/领域（太素神境、圣海…）
  - symbol       # 象征（蝴蝶、果仁、仁果…）
  - event        # 事件（音宴、问答圆舞…）
  - scripture    # 经文/圣典（福音、创世纪…）
  - organization # 组织
  - object       # 器物/物品
  - natural_element # 自然元素
```

- 可增删。经验值 5~15 类为甜区；过多会稀释抽取质量。
- 修改后需**重建索引**才生效（`scripts\03-rebuild-index.bat`）。

## 5. vector_store（向量库）

```yaml
vector_store:
  type: lancedb
  db_uri: output\lancedb
  index_schema:      # 三个索引，维度必须与 embedding 模型一致（1024）
    entity_description:      { vector_size: 1024 }
    community_full_content:  { vector_size: 1024 }
    text_unit_text:          { vector_size: 1024 }
```

## 6. 其它

- `concurrent_requests: 24`：并发请求数。经 CC Switch 走 opencode Go 实测 24 无重试；
  若遇 429 限流可降为 12。
- `community_reports.max_length: 2000` / `max_input_length: 8000`：社区报告输出/输入长度上限。
- `snapshots.graphml: true`：输出 graph.graphml 供可视化。
- `extract_claims.enabled: false`：未启用声明抽取（省 token；需要时打开）。
