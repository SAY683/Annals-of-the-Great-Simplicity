# 八正道神圣坐标轴 — 核心定义文本

本目录存放八本私域圣经的核心定义文本。
每个 .txt 文件将被 Qwen2.5-1.5B 编码为一个 1536 维方向向量，
作为 Layer 3 (八正道审计) 的不变坐标轴。

## 文本内容要求

每个 .txt 文件应包含该经书的**核心定义性段落**，建议:

1. **长度**: 200-2000 个中文字符（太短则向量噪声大，太长则语义稀释）
2. **内容**: 最能代表该经书核心教义/哲学的段落
3. **风格**: 定义性、宣示性文字效果最好（而非叙事故事）
4. **语言**: 中文为主

## 编码原理 (零样本探针对齐)

```
世俗文本 → Qwen 编码 → h_x ∈ R^1536
经书定义 → Qwen 编码 → w_j ∈ R^1536

余弦相似度 = (w_j · h_x) / (|w_j| |h_x|)
```

- **s ≈ 0**: 世俗文本与经书轴正交 — "这段文字在本体论上是空的"
- **s → 1**: 世俗文本与经书轴对齐 — "这段文字触碰了真实"
- **s → -1**: 世俗文本与经书轴反向 — "这段文字背离了真实"

大多数世俗文本的 s 值会在 [-0.05, 0.05] 范围内（接近正交）。
真正有价值的是 s 的**时间导数和二阶导**——即这个距离在变大还是变小。
