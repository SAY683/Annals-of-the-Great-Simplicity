# TRACE-Engine-EDM-Takens-CCM-shehui-llama-470m

## 项目来源

本模型为 **[Annals of the Great Simplicity（太易）](https://github.com/SAY683/Annals-of-the-Great-Simplicity)** 项目中 **TRACE 引擎** 的训练成果。

- **GitHub 仓库**：[SAY683/Annals-of-the-Great-Simplicity](https://github.com/SAY683/Annals-of-the-Great-Simplicity)
- **工程目录**：`Complement/TRACE Engine(EDM-Takens CCM)/trace-engine/models/shehui-llama/`
- **引擎体系**：TRACE Engine 基于 Takens 嵌入定理与收敛交叉映射（CCM），以 LLaMA 架构微调，构建自然语言处理与非线性时间序列分析之间的实证桥梁。
