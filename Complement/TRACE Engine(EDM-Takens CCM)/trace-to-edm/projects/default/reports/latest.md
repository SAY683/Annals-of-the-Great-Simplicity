## 3. 关于零值与负数的数学说明

- **ATE 为 0**: 在 LIGHT 模式下, 若文本过短或无可识别因果结构, OLS 估计会退化为 0. 这不代表算法错误, 而是"无显著线性因果"的统计结果.
- **ATE 为负**: 表示"处理变量增加 → 结果变量减少"的抑制关系, 是因果效应的正常取值范围.
- **refuted_count = 0**: LIGHT 模式不运行反驳测试, 故恒为 0; DEEP/SUPER 模式才会产生非零值.
- **ccm_coverage_pct = 0**: LIGHT 模式不运行 CCM 非线性验证, 故恒为 0.
- **dz_/d2z_ 首行空**: 一阶差分需要至少 2 个连续点, 二阶差分需要至少 3 个连续点, 因此首行/首两行无定义(显示为 —).
- **z_pca / z_八正道 为负**: 投影以均值为 0 进行标准化, 负值表示"低于该维度的平均水平", 完全正常.
- **zscore 为负/正**: 标准分数, 0 为均值, ±1 为一个标准差, 负值表示低于历史均值.
