本项目正式缩写为 **AGS**，对应全称 **A**nnals of the **G**reat **S**implicity（中文名：太易：一部内在宇宙的编年史）。

**使用原则：**
- 在文档、命令行、文件命名、内部沟通中均可使用 AGS 指代本项目
- Netlify 部署站点（sayhelp.netlify.app）名称暂不修改
- README.md 标题中已有标注 `(Annals of the Great Simplicity, 简称 AGS)`
- GitHub 仓库全称仍保留，仅在引用时补充 AGS 缩写

**为什么：** 全称较长，缩写便于日常交流与文档引用。
**如何应用：** 在项目内所有新写文档中，首次提及时可写全称后括注 AGS，后续直接使用 AGS。
